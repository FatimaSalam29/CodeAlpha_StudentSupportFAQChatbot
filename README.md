# Credit Safe Harbor

CRITICAL: CREDIT LIMIT AND FINAL REPORT

Before reaching any usage or credit limit, you must:

1. Save and preserve all completed work.

2. Stop starting new features when credits are running low.

3. Generate a detailed progress report in your latest response.

4. Clearly list completed tasks and remaining tasks.

5. Explain exactly how to complete each remaining task.

6. Mention modified files and the exact point where development stopped.

7. Provide a continuation prompt so I can resume later without rebuilding anything.

Never wait until credits are completely exhausted to report progress. Prioritize saving the project and reporting its status.
